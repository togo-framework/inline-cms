# inline-cms — docs

Turn any public site into its own CMS: schema-driven edit-in-place, admin bar, inline fields and pickers, reorder — no separate dashboard.

- **Source:** https://github.com/togo-framework/inline-cms
- **Reference app:** https://fadymondy.com

## Install

```bash
togo install togo-framework/inline-cms
```

The plugin self-registers on blank-import (no manual wiring). See the top-level
README for usage. This plugin was extracted from the fadymondy.com togo app as
part of turning that site into a reusable plugin suite.
